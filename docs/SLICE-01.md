# SLICE-01：单手生存战斗闭环

## 目标

用一个 3 分钟竖屏关卡验证以下核心体验：玩家只负责走位，武器自动攻击；击杀转化为经验；升级选择改变火力；怪潮压力随时间上升。

## 本切片包含

1. 单指虚拟摇杆移动，键盘 WASD/方向键仅作为桌面调试补充。
2. 最近目标自动瞄准的脉冲弹。
3. 普通敌人、阶段性精英、接触伤害和受击无敌时间。
4. 经验能量掉落、吸附、升级暂停和三选一。
5. 五条局内成长：伤害、攻速、齐射、环刃、生命。
6. 3 分钟胜负条件、结算和原地重开。
7. 顶部安全区 HUD：经验、倒计时、击杀和生命。

## 不包含

- 局外养成、装备、商店、广告、付费和账号。
- 关卡地图、剧情、美术资产量产、音频和联网。
- 微信上传、体验版、审核或发布。

## 自动验收

- 规则测试覆盖自动攻击节奏、接触伤害无敌帧、经验升级和胜利条件。
- 项目验证检查场景、组件 UUID、微信构建配置、触控尺寸和 Mini Game 兼容语法。
- Creator TypeScript 检查通过。
- Creator 3.8.8 微信小游戏 Debug 构建通过，入口文件与工程配置存在。

## 手动验收建议

1. 拖动时角色方向响应连续，松手立即停下。
2. 不操作攻击键也会稳定发射；升级选择期间战斗完全暂停。
3. 前 30 秒能理解击杀—拾取—升级闭环。
4. 90 秒后怪潮明显更紧张，但仍能通过走位脱身。
5. HUD 在移动和密集怪潮中仍可一眼读取。
