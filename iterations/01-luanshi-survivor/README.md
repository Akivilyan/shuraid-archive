# 报，蜀军来劫粮

新开发任务请先阅读 [PROJECT-HANDOFF](docs/PROJECT-HANDOFF.md)。该文档记录当前确认方向，并覆盖旧设计文档中的过期内容。

《报，蜀军来劫粮》是三国武将生存 Roguelite 的微信小游戏灰盒。当前验证三类武将的自动战斗、局内三选一与构筑取舍，不包含局外成长、商业化和正式美术。

设计边界见 [DIRECTION-01](docs/design/DIRECTION-01.md)。
战斗骨架见 [CLASS-CORE-01](docs/design/CLASS-CORE-01.md)。
首版视觉规范见 [ART-DIRECTION-01](docs/design/ART-DIRECTION-01.md)。

## 当前切片

- 竖屏单指移动与自动攻击；
- 关羽、黄忠、诸葛亮三名可选武将，分别复用扇形、投射物、目标区域三种攻击算法；
- 敌人掉落经验，靠近后自动拾取；
- 升级暂停，提供三个不同技能选项；
- 每名武将一个固有技能、三个专属战法；三名武将共用三个简单被动；
- 单局最多取得两个额外战法与两个被动，三选一存在真实放弃；
- 经验需求随等级加速上升，局内最高 12 级，满级后敌人不再掉落经验；
- 所有可用技能满级后，后续升级转为少量恢复并自动继续战斗；
- 技能三级质变；
- 魏、吴两套Q版士兵配色与冠饰，覆盖步兵、疾行兵、盾兵、弓兵和将帅；
- 竖直角色本体配合待机、移动、攻击和受击四组离散姿态帧；
- 敌人受击压缩、火花、伤害数字和轻量实体挤压；
- 两分钟快速验证局，击败首领获胜；
- Q版主界面、武将信息页、设置页和统一的卡通战斗占位美术。
